## Game Adaptation

The source supplies the fixed clockwork apparatus, Intake/Output booths,
selection controls, key winding, timed processing and prohibition on
unapproved biological testing. Only a bounded pre-approved nonliving trial is
represented here. Formal guard/authorization staffing, internal mechanism,
source-scale geometry and the full five-setting test space are not simulated.

The input is one actual original protective vest. Coarse yields two maintenance
packs; Very Fine yields a short-lived high-reduction shell. These are original
game results, not canonical experiments or a universal deterministic table.
Sixty device ticks, two activation ticks, item quantities and three port
positions are authored abstractions, not mass/energy calculations or literal
minute/booth dimensions.

Neither output qualifies as another input. No biological, weapon, medical or
arbitrary request execution is implemented. The operator may leave after
activation; the actual machine owns the input and cycle. The retired input ID
remains with amount0 after successful output for provenance, not as reusable
gear. Output retains actual input condition/operator/setting/dates.

This earns a capability beyond ordinary equipment repair: independent
device-owned work and an irreversible equipment choice, not a repaired copy
or a free replenishment loop.
