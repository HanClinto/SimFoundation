## Verified Source Summary

The article describes 049-2 instances as reanimated subjects created by SCP-049's procedures, without their former memories or higher mental function and with basic movement and responses. They are generally inactive, but can become aggressive when provoked or directed by SCP-049. The discovery account and an observation log describe personnel neutralizing instances.

The source does not establish universal invulnerability for SCP-049; this implementation neither includes SCP-049 nor encodes such a claim. It also does not infer that neutralization is the only possible interaction with every 049-2 instance.

## Game Adaptation

The opt-in test represents one already-provoked instance. Its starting appearance, pursuit radius, target roster, speed, attack preparation/recovery, functional damage and integrity are original game balance. It is not a default resident, campaign incident, or simulation of reanimation. It does not spread infection or create additional instances.

The bounded sandbox deliberately ignores non-enrolled staff as adversary targets and suspends after the response team withdraws. This protects unrelated facility workflows while tactical mechanics are tested; neither rule is attributed to the source. Later unrestricted incidents need general actor damage, casualty ownership, and civilian response before these restrictions can be removed.
