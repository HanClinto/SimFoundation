## Game Adaptation

The bounded runtime scene uses the article's direct observation constraint,
hostility, multiple-person maintenance procedure and locked enclosure. It uses
original authored geometry, turn movement, fatigue/commitment limits and cleaning
timing. Automatic blinking and full source-level motion/violence are not modeled.
Conscious direct Watch is not a camera or ambient visibility check.

The former sculpture photograph has separate rights concerns and is not part of
this implementation. No source image, sculpture likeness or new visual asset
was copied. Runtime prose is original adaptation text with explicit attribution.
See `src/simulation/catalog/quests/scp173/README.md` for playable limits.
