# Bounded Local Capture Job

Once equipment, subdual, physical restraints and transport existed, their
routine local sequence could become one useful manager order. Capture is a
normal queued action naming a subject, the actual restraint and a destination.
It delegates to the existing Subdue, Restrain, Take and Move handlers rather
than duplicating effects or creating another executor.

The next phase follows current physical facts. Already effective custody skips
unneeded intervention; a consumed last charge does not block later restraint
or movement. An unavailable compatible band is checked before spending a charge
on an impossible plan. Phase-local work is ordinary serializable queue data,
not a scripting language, route plan or global job registry.

Cancellation/incapacity retains every completed physical effect and cost.
Resumption uses actual subdual/attachment/carrier facts, not rollback or free
replacement gear. Completion means the same restrained living subject is
carried at the selected local loading point. Cross-site send, clinical work,
cell preparation and intake remain separate explicit decisions.

Tests compare the whole physical site state and elapsed ticks against the
primitive command sequence, plus partial-work replay, last-charge completion,
missing gear, blocked destination and interrupted/removed targets. Core39
discards incompatible queued-action data without migrations.
