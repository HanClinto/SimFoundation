# Curated Hosting With Existing Work

## Decision

Choose SCP-2006 rather than concurrently developing an observation framework
for SCP-173. Reuse ordinary physical Study and recurring Service for one
bounded protocol: practical rehearsal by each host, an actual nearby audience,
and a sequence of distinct curated prints.

An optional per-actor Study plan records the same named finding independently
for each actor. Service can require that actor's actual finding at the current
site and a specified nearby participant. There is no duplicated qualification
counter or general acting statistic.

Service can retain rather than consume an input, and can require an input
identity not previously recorded at that counter. Existing receipts now state
whether the input was consumed. A reusable in-use input is claimed by active
queue work; Take cannot remove it without completion/cancellation, and another
counter cannot simultaneously use it. Lost or changed active input fails or
blocks explicitly rather than completing a phantom screening.

The source-specific programme set and routine are catalog data. Normal supply
selection, repair, work, deadlines, duty and care breaks remain shared with the
diner. There is no second screening executor, arbitrary media interpreter,
psychology framework or simultaneous SCP-173 showcase.

Core version 19 discards incompatible snapshots. Current-version tests cover
host identity, distinct preserved programmes, unapproved media, cancellation,
in-use ownership, absent audience, missing repairs, replay and exhaustion.

## Limits

The fixed audience does not simulate arbitrary shapeshifting, continuous
monitoring or actual beliefs. Coverage is a bounded protocol fact, not evidence
that the full article's containment behavior was executed. No copyrighted
movie screenshot or source dialogue is used. Original programme titles and
adaptation boundaries are documented beside the source-backed catalog entry.
