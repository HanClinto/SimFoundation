# Explicit Wound Care, Not A Universal Heal

Dangerous intervention now produces real wounds as well as blood loss. A
surviving worker disabled by wound severity needs a finite path back to work,
without changing the default blood/postoperative course into a universal cure.

The existing Nurse action accepts an explicit `wounds` course at a supporting
clinical bed. It uses a different real supply, twenty productive ticks and a
bounded severity reduction. The same physical proximity, training, stopped
bleeding, bed/patient occupancy, paid-input and interruption rules apply.
There is no second treatment executor.

Recovery reduces the severest remaining wound first, with stable identity
ties. Each original wound retains its ID and per-course actor, action, supply,
date and reduction provenance. Interrupted work keeps both partial benefit and
spent supplies. No background regeneration, receipt replay or wound deletion
occurs. Only a completed supported course can clear corresponding wound
incapacity after remaining health limits are satisfied. Death, major organ
trauma and unrelated inability cannot be cured by this course.

The original intervention survivor transcript deliberately incurs impacts,
uses finite stabilization charges, withdraws with actual worn equipment and
receives separate wound and blood care at home. Core version25 discards older
development saves; no real medical recipe or procedure is represented.
