# Individual watch duty

Manager-first coverage needs a worker to return to a chosen post after ordinary
rest, without a general shift scheduler or a free-rest abstraction.

Store one optional pawn intent: subject ID and physical post. It is exclusive
with future service duty. Assignment/clearing does not erase current paid or
explicit work, and local human/subject/floor checks apply.

Existing emergency concerns retain priority, so an interruption for actual
injury or threat executes its response rather than repeatedly recreating watch.
The autonomy selector then chooses actual critical restorative work when
available, otherwise ordinary Move to the post and Watch. Self-chosen watch
warns/releases when a satisfiable critical need arises; the worker uses existing
food/bed actions and later returns. Explicit player Watch semantics remain
unchanged. Missing visibility/post access is not counted as active coverage and
is visible in the workboard.

This policy is deliberately individual, not safe automatic relief. Multiple
workers can need rest together. A manager must stagger commitments, retain
another active observer or close the door. Supplemental companion gaze does
not replace human maintenance staffing. There is no second pawn executor,
timing registry, invisible replacement or spontaneous bed/food.

Normal play transports the existing spare guest bed from home while preserving
another observer; the assigned worker sleeps and returns to the same post.
The physical furniture stays in the field, changing later home loadout choices.
