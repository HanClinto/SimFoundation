# Persistent Text Campaign

## Decision

The approved unattended mandate makes the replacement text session a persistent
home-site management loop, not another isolated quest. The default console now
starts a finite home roster, a Blackwood outpost, a remote SCP-1370 gallery and a
Kestrel depot. Existing isolated quests remain explicitly selectable integration
trials. The browser continues to run its unchanged archived engine.

Catalog owns named campaign setup, route rules, finite transport costs and the
finding prerequisite. Application owns the session and label lifecycle. Core
still knows only generic entities, actions, sites and transfers; it imports no
campaign content. The campaign observes the actual home study finding instead
of saving a second unlock flag or quest completion ledger. No outcome destroys,
resets or freezes a site.

`prepare` assigns existing staff ordinary movement orders to two loading pads
and turns their autonomy off so they remain available for departure. `send`
requires completed queues and physical presence. Core transfer accepts an
explicit loading radius (zero by default), allowing a two-person team to stage
on adjacent tiles without bypassing ordinary pawn collision. The existing
transfer owns staff and their full carried trees during transit and retries
blocked admission. Staff retain global identities and stable labels; console
aliases remain usable after transfer and reject ambiguity.

One physical transport docket beside the home loading pad pays for an outbound
group and its return. It is consumed only after successful departure. Returns
never depend on a remaining outbound balance. This is an authored allocation,
not vehicle fuel simulation. The depot has finite recoverable supplies, not a
restocking reward counter. The field kit is a real carried study requirement,
competing with return cargo for the ordinary one-object carry slot.

## Consequences

Blackwood evidence must return home for comparison with the two independent
records. The resulting finding opens Kestrel. Staff can withdraw with only part
of the evidence and spend another finite allocation to revisit the unchanged
site. SCP-1370 uses the same transfer into an actual home display bay. The bay
keeps its display position two tiles from the automatic door so the recovered
exhibit does not itself prevent closure.

Session version 4 adds campaign state and discards earlier sessions without
migration. Core snapshot shape is unchanged. Save/replay, lost-resource and
single-owner invariants are tested through normal CLI commands. The colocated
campaign walkthrough is test-only and is never imported by runtime code.

This is not a universal assignment planner, a second executor, living escort,
permanent death or an infinite procurement economy. The original campaign has
no authored combat hazard. Existing medical stabilization does not regenerate
lost blood or restore permanent incapacity. Subjective fun remains unproven by
automated play; the visible decisions so far are team/cargo allocation, leaving
equipment in the field, and spending finite trips on partial recovery.
