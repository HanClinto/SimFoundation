# Bounded Source-Backed Dispensing

## Decision

SCP-294 earns a small generic dispensing action, not a recipe language or
free-form request interpreter. Catalog owns four named request definitions,
credit and adaptation limits. A facility can expose liquid requests naming an
accepted source definition and output definition, or a paid refusal. Core owns
physical approach, occupation, payment and source-to-sample accounting.

The command names the concrete source. It must be an intact ground item at the
same site, matching the request's definition. The machine transfers a portion
of that record's material/quantity into a new sample, never synthesizing a
parallel supply balance. Finite coin payment occurs on the first productive
tick; source withdrawal and output creation happen together on completion.
Queue state owns work and the spent-payment reference. New command submission
strips caller-supplied payment/progress so it cannot spoof a paid attempt.

Cancellation keeps spent coins and does not create a partial liquid cup.
Occupied output and absent resources block visibly. A facility-owned monotonic
sample suffix creates stable IDs underneath its globally stable machine ID.
Sample provenance and dated machine records preserve what was actually
dispensed; a rejected solid request records no sample or source debit.

Existing delivery transports samples. Existing physical study accepts two
distinct samples and records their IDs; there is no second research executor.
Source-backed sample fields are plain serializable data. Core version 12
discards incompatible saves without a migration or deep validation layer.

## Limits

The source snapshot and attribution were reviewed before adaptation. Hazardous,
biological and abstract requests are excluded. The authored harmless tracer is
not the source article's mixture or a reproducible chemical recipe. Cup material
and liquid quantity are abstracted into one carried sample; nested vessels,
spillage, machine freight, remote-site extraction, throughput cooldown and
automatic restocking are deferred.

The first sample comparison is evidence, not a new campaign route or generic
research currency. Its value as player-facing experimentation is still a
hypothesis; the repeat/depletion/paid-interruption choices are inspectable, but
automated tests cannot establish subjective fun.
