# Physical supplemental attention

SCP-131's specific documented interaction with SCP-173 justifies a bounded
supplement to the existing attention scene, not a universal camera or a
replacement human work crew.

Add one authored pawn capability: target definition whitelist and nearby-human
range. Current attention derives from actual capability, independent ground
availability, sight of the supported source and a visible conscious human.
There is no stored observer registry, second action executor or remote buff.
Independent observer availability is shared with impact recording and explicitly
excludes active sleep.

Facility supervision explicitly counts human observers, and guarded relief
requires a real replacement Watch commitment. Natural supplemental gaze does
not satisfy either staffing contract.

Existing escort and atomic transport preserve their identities. Their authored
visit has no hunger/fatigue need, so the care-admission boundary refuses ordinary
bed admission instead of giving a nonsleeping source a sleep job.

the default remains home. This lets actual annex research authorize the visit
without copying a finding or creating a research-points ledger.
